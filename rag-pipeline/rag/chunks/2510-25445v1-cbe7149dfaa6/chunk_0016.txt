Framework Primary Mecha- nism Functional Paradigm and Repre- sentative Applications

LangChain [41, 62, 63, 64, 65] Prompt Chaining Orchestrates linear sequences of LLM calls and API tools. Replaces symbolic planning with stochastic generation of next steps. Applica- tions: Multi-step workflow automa- tions, automated medical reporting [66].
