To connect with internet:

Hotspot

If the in-built internet connectivity feature is available, you can use the Hotspot feature to provide internet connectivity to other devices.

To provide internet access via Hotspot

1. Navigate to Connectivity Application, Enable Hotspot.

2. The system will display Hotspot Name and password.

3. Look for the same hotspot name in the device you want to connect with, enter the password and to get connected.
