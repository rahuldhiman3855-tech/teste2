APPLICATIONS HMI Doodle

Activating Doodle My sticker / Startup Widget

1. Tap App Launcher Icon Select Settings, and select HMI Doodle Application

HMI Doodle

2. Select the My Sticker/Startup Image option. The system displays My Sticker/Startup Image Settings screen.

Doodle is a user experience customization solution designed for TATA vehicles. With Doodle feature, you can customize the infotainment system screen. Sticker image or startup image can be selected from the iRA App over smartphone, when connected to Infotainment system.

3. Select the required option to

Activate

Doodle allows you to:

− On Tapping Activate, the system will display the image/sticker after the inactivity period.

• Use My Sticker/Startup Image functionality and display desired image on display screen.

Note: Inactivity period is by default set to 15 seconds.

• Use Smartphone to personalize My Sticker and Startup Image through Connect NXT App
